Lab1 操作系统概述与环境搭建
一、实验目的

    掌握 RISC-V 体系结构基础，理解处理器特权级、内存布局与异常处理机制。
    搭建 QEMU + RustSBI 模拟环境，完成内核最小可执行程序编译与运行。
    实现内核态输出、简单内存读写，理解裸机程序的链接脚本与启动流程。
    熟悉 rCore 项目结构、构建系统与调试方法。

二、实验环境

    主机系统：Ubuntu 20.04 / 22.04
    工具链：rustup、rustc、cargo、riscv64gc-unknown-none-elf
    模拟器：qemu-system-riscv64
    Bootloader：RustSBI
    语言与框架：Rust、rCore-Tutorial

三、实验内容与步骤

    环境配置
        安装 Rust 环境并添加 RISC-V 目标平台
        安装 QEMU 与相关依赖库
        配置镜像源加速编译下载
    最小内核实现
        编写无标准库裸机程序
        实现内核入口 _start，初始化栈空间
        实现基于 UART 串口的字符串输出
        编写链接脚本指定代码段、数据段与内存布局
    RustSBI 加载与 QEMU 启动
        将内核编译为 RISC-V 裸机目标文件
        使用 QEMU 加载 RustSBI 并启动内核
        实现 Hello, World! 内核打印
    简单内存与异常测试
        直接读写物理内存验证地址空间
        触发非法指令、缺页异常，观察内核崩溃行为
        理解 SBI 调用与 ecall 基础机制

四、实验结果

    成功搭建 RISC-V 操作系统开发环境。
    编译并运行最小内核，在 QEMU 中正常输出字符串。
    能够观察处理器异常行为，理解裸机程序执行流程。
    熟悉 Makefile 与项目构建流程，能够独立清理、编译、运行内核。

五、实验思考与总结
Lab1 让我理解了操作系统的 “起点”：从上电、Bootloader 加载，到内核第一条指令执行。无标准库环境下的编程要求手动管理内存与资源，Rust 的安全特性有效避免了空指针、越界等常见底层错误。同时初步认识到特权级、异常、物理内存等核心概念，为后续进程、虚拟内存实验打下基础。
